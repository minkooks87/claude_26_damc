## 3. 이 연구에서 특히 조심할 부분

| 쟁점 | 어떻게 쓸까 |
|---|---|
| **결과를 본 뒤 분석 조건을 정함** | 음주 기준, 1잔 g, 흡연 범주, 경향성 삭제, 보정 모형, 민감도 목록을 여러 결과를 본 뒤(2026-11-16 ~ 11-23) 정했습니다. 방법이나 한계에 솔직하게 쓰고, 시도한 기준 전체(`output/21_ptest/ptest_log.csv`)를 부록 표로 싣습니다. 숨기면 가장 큰 약점이 됩니다 |
| **"차이 없음"이라고 쓰지 않기** | 주질문(남 p = 0.100)은 "차이를 확인하지 못했다"로 씁니다. 효과 크기와 신뢰구간을 함께 보고합니다(OR의 비 1.45, 95% CI 0.93–2.26) |
| **부질문의 유의한 결과** | 남자 소실군(p = 0.043)은 유일한 유의 결과이고, 민감도에서 p가 0.04–0.07을 오갑니다. 확증이 아니라 탐색적·가설 생성 결과로 표현합니다 |
| **두 군의 신뢰구간으로 판단하지 않기** | 지속 홍조군 OR의 구간(1.02–2.30)이 1을 넘는 것과 교호작용이 유의한 것은 다른 문제입니다. 교호작용 검정과 OR의 비로만 판단합니다 |
| **곱셈 척도 vs 덧셈 척도** | 효과수정 보고에서는 덧셈 척도 교호작용(RERI)도 함께 보고하길 권합니다(Knol & VanderWeele 2012 권고). 지금은 곱셈 척도만 있으므로 추가로 계산하거나 한계에 적습니다 |
| **M3S의 p = 0.046** | 매개변수를 보정한 모형이라 결론에 쓰지 않는 이유를 본문에 적습니다 |
| **여성 결과** | 사례 수(427명, 비교 칸 5–15명)의 한계를 먼저 밝히고 혈청 요산 결과를 함께 제시합니다. 소실군(사례 5명)은 해석하지 않습니다 |
| **복합표본 보고 규칙** | 모든 표에 비가중 n과 가중 %(또는 가중 평균)를 함께 적습니다. 가중 인원을 "n"이라고 쓰지 않습니다. 표 각주에 연도, 가중치, "n은 비가중 표본 수, %와 평균은 복합표본 가중 추정치"를 적습니다 |
| **용어 통일** | 내부 용어(주질문·부질문·M2S·S2)는 논문 용어로 풀어 씁니다. 예: "지속 홍조군 대 비홍조군의 효과수정", "주 모형(Model 2)", "절주 지침 기준(남 16 g/일, 여 8 g/일)" |

## 4. 한계에 넣을 것

1. **단면 설계:** 인과관계와 시간 순서를 알 수 없습니다. 고요산혈증이나 통풍 위험을 알게 된 사람이 술을 줄였을 수 있습니다(역인과).
2. **노출 측정:** 음주량은 설문 범주 대푯값이라 오분류가 있을 수 있습니다(민감도 분석으로 일부 확인). 1잔의 알코올 g은 가정입니다.
3. **홍조 측정:** 홍조 이력은 회상에 의존하고 ALDH2 유전형은 없습니다. 홍조 소실은 내성 형성이나 음주 습관 변화와 얽혀 있을 수 있습니다.
4. **측정하지 못한 교란:** 식이(퓨린, 과당), 요산강하제·이뇨제 복용, 주종(특히 맥주).
5. **선택:** 대상을 최근 1년 음주자로 한정했고, 아파서 술을 끊은 사람(sick quitter)은 다루지 못했습니다. 보정변수 결측으로 438명이 빠졌습니다(포함·제외 비교표 `05_included_vs_excluded.csv`로 제시 가능).
6. **작은 군과 다중 비교:** 남자 소실군 341명, 여자 소실군 236명. 유의한 결과는 하나이고 경계 근처입니다.
7. **결과를 본 뒤 정한 분석 조건**(3절).
8. **일반화:** 한국 성인 음주자에 한정됩니다.
