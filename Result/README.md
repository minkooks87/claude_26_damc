# Result

우리 조가 **조사한 결과**와 **연구 중간 결과**를 모아 정리하는 폴더입니다.

## 다른 폴더와의 차이
| 폴더 | 무엇을 두나 |
|---|---|
| `reference/` | 논문 원문(PDF)과 논문별 요약 |
| `code/` | 분석 코드 |
| `output/` | 코드를 실행해 자동으로 나온 표·그림·보고서 |
| `meeting/` | 회의 계획과 회의록 |
| **`Result/`** | **조원이 정리한 조사 결과와 중간 결과.** 예: 음주 기준 결정안, 보정변수 표, DAG 그림, 교수님 미팅 자료, 결과 해석 메모 |

## 올리는 방법
- **파일 이름:** 날짜와 내용을 함께 적어요 (예: `2026-11-18_음주기준_결정안.md`, `2026-11-18_보정변수_DAG.png`).
- **출처 표시:** 수치가 있으면 어느 코드나 `output/` 파일에서 나온 것인지 적어요.
- **AI 사용 표시:** 생성형 AI(Claude 등)의 도움을 받았으면 문서에 적어요.
- **올리지 않는 것:** 국건영 원시자료(`data/`, `.sav`, `.sas7bdat`)는 올리지 않아요.
- **올리는 순서:** README 8장 규칙대로 브랜치를 만들고 PR로 올려요.
