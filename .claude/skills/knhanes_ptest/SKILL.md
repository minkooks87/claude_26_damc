# knhanes_ptest: 기준별 질문 p값 빠르게 구하기

기준을 받아 스크립트 하나를 실행하고, 질문별 p값 표를 한국어로 전한다. 자료 준비에 약 5초, 기준 하나에 약 5초 걸린다. 기준이 여러 개면 기준 목록 파일로 한 번에 돌린다(2절).
변수 정의·대상 선정·복합표본설계는 본 분석(`code/13_v3_main_analysis.R`의 0–3절)을 그대로 실행해 만들므로 본 분석과 같다.
프로젝트 규칙(CLAUDE.md)을 지킨다. `data/`는 읽기만 한다.

## 1. 사용자의 말을 옵션으로 바꾼다

| 사용자가 말한 것 | 옵션 |
|---|---|
| 남녀 같은 절단점 "15·30 g/일", "5잔, 15잔" | `--cuts=15,30` |
| 남녀 다른 절단점 "남자 2.4·10, 여자 0.4·2.5" | `--male=2.4,10 --female=0.4,2.5` |
| 연속형 "하루 잔수로", "연속형으로" | `--drink=linear` (하루 1잔당 = 7 g/일당) |
| "10 g/일당", "100 g/주당" 처럼 단위 지정 | `--drink=linear --per=10` (g/일 단위. 100 g/주 = `--per=14.2857`) |
| "스플라인", "용량-반응 모양" | `--drink=rcs` (Harrell 제한 삼차 스플라인, 매듭 4개 = 성별 5·35·65·95 백분위, 선형항 단위 10 g/일). 상호작용은 3 df, '용량-반응' 줄에 비선형성 검정(2 df) |
| "경향성 검정", "P for trend" | 범주형에 `--trend=median` 추가. 성별·범주별 g/일 중앙값(비가중)을 점수로 1 df 경향성 상호작용과 홍조군별 음주 경향성(10 g/일당 OR)을 함께 낸다 |
| "log로", "두 배당" | `--drink=log2` (log2(잔/주 + 1)) |
| 보정변수 | `--covars="묶음1;묶음2"` (아래 표). 없으면 `Model 2;Model 3` |
| 혈청 요산(연속형 결과)도 | `--outcome=both` (요산만이면 `uacid`) |
| 폐경 후 여성 빼고 | `--pop=premeno` (남자는 전체 유지) |
| 임신·수유 여성 빼고 | `--pop=nopreg` |
| "1잔을 8 g(10 g)으로 보면" | `--gram=8` (기본 7) |
| 기록에 남길 이름 | `"--label=이름"` |
| 기준 여러 개를 한 번에 | `--batch=파일` (2절) |

절단점과 연속형 단위는 **g/일**이다. 기본은 국건영 1잔 ≈ 7 g이라 **g/일 = 주당 잔수**이고, `--gram`을 바꾸면 g/일 = 주당 잔수 × gram ÷ 7로 환산한다. 사용자가 잔 단위로 말하면 1잔 = 7 g 기준에서 그 숫자를 그대로 쓴다고 알린다.
`a,b`는 a 미만 / a 이상 b 미만 / b 이상의 3군이고, 경계 하나면 2군, 셋이면 4군이다. 남녀 절단점 개수는 같아야 하고, 같은 값을 두 번 쓰면 멈춘다.
어느 성별에서 범주가 비면(예: 여자 500 g/일 이상) 그 기준은 건너뛰고 알린다.

### 보정변수 묶음

`;`로 묶음을 나누고, 묶음 안은 `+`로 잇는다. 프리셋, 변수 이름, `-변수`(빼기)를 섞을 수 있다.
예: `"Model 2;Model 2+he_bmi;age+f_edu+f_smk3;Model 3-egfr10"`

| 프리셋 | 변수 |
|---|---|
| Crude | 없음 |
| Model 1 | age, meno_cov |
| Model 2 (주 모형) | age, f_edu, f_incm, f_year, f_smk, f_pa, meno_cov |
| Model 3 | Model 2 + he_bmi, f_htn, f_dm, egfr10 |

**폐경 상태(meno_cov)는 항상 들어간다.** Crude를 뺀 모든 묶음에 자동으로 추가되고, 사용자가 직접 만든 묶음에도 들어간다. 빼려면 묶음에 `-meno`를 적는다(예: `Model 2-meno`).
- 여자 모형에만 들어간다. LW_ms(8기 PDF p.190)로 폐경 전(2·3·4), 폐경 후(5·6), 기타(7) 세 범주이고, 9(모름·무응답)는 결측이라 그 여성은 빠진다.
- 남녀 통합 모형(부질문 2)에서는 성별 상호작용 밖에 여자 전용 지시변수(meno_post, meno_other)로 넣는다.
- 폐경이 효과수정변수인 폐경 3원 검정과 `--pop=premeno`에서는 자동으로 뺀다.

| 변수 | 뜻 | 변수 | 뜻 |
|---|---|---|---|
| age | 연령(세) | age10 | 연령 10세 범주 |
| f_edu | 교육수준 | f_incm | 소득 4분위 |
| f_year | 조사연도 | f_pa | 유산소 신체활동 |
| f_smk | 현재흡연 2범주 | f_smk3 | 흡연 3범주(비·과거·현재) |
| he_bmi | 체질량지수 | egfr10 | eGFR(10 단위) |
| f_htn | 고혈압 유병(HE_HP) | f_htn_dx | 고혈압 의사진단 |
| f_dm | 당뇨병 유병(HE_DM_HbA1c) | f_dm_dx | 당뇨병 의사진단 |
| meno_cov (또는 meno) | 폐경 상태(여자만, 기본 포함) | | |

목록에 없는 변수를 요청받으면 스크립트가 멈춘다. 그 변수를 쓰려면 지침서에서 정의를 확인해 `code/13`에 변수를 만든 뒤 `scripts/ptest.R`의 `cov_avail`에 추가해야 한다고 사용자에게 알린다.

## 2. 실행한다

프로젝트 폴더에서 R을 전체 경로로 실행한다. 옵션 설명은 `--help`로 볼 수 있다.

**기준 하나**

```
& "C:\Program Files\R\R-4.6.0\bin\Rscript.exe" --vanilla .claude/skills/knhanes_ptest/scripts/ptest.R --male=2.4,10 --female=0.4,2.5 "--covars=Model 2;Model 3" "--label=성별 삼분위"
```

PowerShell에서는 공백이나 `;`가 든 옵션을 `"--covars=..."`처럼 통째로 따옴표로 감싼다.

**기준 여러 개: 기준 목록 파일**

기준이 둘 이상이면 scratchpad에 기준 목록 파일(UTF-8)을 만들어 `--batch`로 한 번에 돌린다. 자료를 한 번만 읽어 훨씬 빠르다. 한 줄에 기준 하나, `#`으로 시작하는 줄은 주석이다. 공백이 든 옵션은 줄 안에서도 `"--label=이름 공백"`처럼 따옴표로 감싼다. 명령줄에 함께 준 옵션은 모든 줄에 공통으로 적용되고, 줄에 같은 옵션이 있으면 줄의 값이 이긴다.

```
# 기준목록.txt
"--label=C01 15·30 g/일 3군" --cuts=15,30
"--label=C02 스플라인" --drink=rcs
"--label=C03 WHO 성별" --male=25,60 --female=15,40
```

```
& "C:\Program Files\R\R-4.6.0\bin\Rscript.exe" --vanilla .claude/skills/knhanes_ptest/scripts/ptest.R --batch=기준목록.txt "--covars=Model 2;Model 3"
```

모든 줄의 옵션을 자료를 읽기 전에 먼저 검사하므로, 틀린 줄이 있으면 "기준 N번 줄"과 함께 바로 멈춘다. 같은 기록 파일에 쓰므로 스크립트를 동시에 두 개 돌리지 않는다.

## 3. 결과를 전한다

연구 질문(`분석계획서.md` 1장, 2026-11-22 개정):

- **주질문:** 남녀 각각에서, 성별 기준으로 나눈 음주 수준과 고요산혈증의 관계는 비홍조군과 지속 홍조군 사이에 연관성이 다른가? (범주별 공동 검정)
- **부질문 1:** 남녀 각각에서, 같은 관계가 현재 홍조가 없는 사람 가운데 홍조 소실군과 비홍조군 사이에 다른가? (범주별 공동 검정)
- **부질문 2:** 주질문의 경향성. 음주 수준이 높아질수록 위험이 커지는 기울기가 지속 홍조군에서 비홍조군보다 큰가? (1 df, `--trend=median` 필요)
- **부질문 3:** 부질문 1의 경향성. 홍조 소실군의 기울기가 비홍조군과 다른가? (1 df, `--trend=median` 필요)
- 이전 부질문 2(성별 3원 교호작용)는 2026-11-22에 삭제했다. 스크립트는 기록이 이어지도록 이 검정을 계속 출력하며, 기록과 출력의 '구분' 칸에는 옛 이름 "부질문 2"로 남는다. **전할 때는 "참고(삭제된 이전 부질문 2)"로 부르고 연구 질문으로 다루지 않는다.**
- 연구 질문의 부질문 2·3은 스크립트 출력에서 '구분'이 각각 "주질문"·"부질문 1"이고 검정 이름에 "경향성"이 붙은 줄이다. 전할 때는 부질문 2·3으로 바꿔 부른다.

스크립트가 출력하는 검정은 다음과 같다(결과마다, 보정 묶음마다). 주질문과 부질문 1은 홍조 이력 3군(비홍조 기준·홍조 소실·지속 홍조)을 한 모형에 넣고 각 상호작용항을 검정한다.

| 구분 | 검정 | 대상 |
|---|---|---|
| 주질문 | 음주 × 지속 홍조 (비홍조 대비) | 남, 여 |
| 부질문 1 | 음주 × 홍조 소실 (비홍조 대비) | 남, 여 |
| 부질문 1(탐색) | 홍조 소실 vs 지속 홍조 | 남, 여 |
| 주질문·부질문 1, 경향성(`--trend=median`일 때) | 연구 질문의 **부질문 2·3**: 음주 점수 × 지속 홍조 / × 홍조 소실 (1 df) | 남, 여 |
| 부질문 2 *(출력 이름. 삭제된 이전 질문)* | 지속 홍조 vs 비홍조 차이 × 성별(통합 모형). 전할 때 "참고"로 부른다 | 남녀 전체 |
| 부질문 2(탐색) *(출력 이름)* | 지속 홍조 vs 비홍조 차이 × 폐경. 전할 때 "탐색: 폐경 전후 차이"로 부른다 | 여자(`--pop=premeno`면 생략) |
| 탐색적 분석 | 홍조 체질(과거 또는 현재 홍조) vs 홍조 없음 | 남, 여 |
| 참고 | 홍조 이력 세 군 공동, 현재 홍조 2군(계획 발표의 주질문)과 그 성별 3원 | 남, 여, 남녀 전체 |

전할 때 지킬 것:

스크립트가 함께 출력하는 것:

- **대상 인원:** 범주형이면 성별·음주 수준별 비가중 n과 가중 %, 그리고 홍조 패턴 4군(비홍조·홍조 소실·지속 홍조·신규 홍조) × 음주 수준의 비가중 n(고요산혈증 사례). 연속형이면 홍조 패턴별 g/일 요약.
- **효과 크기:** 1 df 검정은 그 값, 범주형 여러 df 검정은 가장 높은 음주 수준의 OR의 비(해당 군 OR ÷ 비교 군 OR, 저음주 대비)와 95% CI.
- **무효 표시:** 칸이 비어 계산이 성립하지 않는 검정(분리)은 p 자리에 "무효"로 나오고 효과 크기 표에서도 빠진다.
- 남녀 절단점이 다르면, 부질문 2가 '같은 양'이 아닌 '성별 기준 안의 상대 수준' 비교라는 안내가 붙는다.

전할 때 지킬 것:

- **질문별 p 표를 보여 준다.** 행은 질문, 열은 보정 묶음. 범주형이면 칸별 비가중 n(사례)과 가중 %도 요약한다(프로젝트 규칙: 비가중 n과 가중 추정치를 함께).
- **비고를 빠뜨리지 않는다.** "사례 10명 미만 칸 있음"은 해석하지 않는 검정, "무효"(분리)는 계산이 성립하지 않는 검정이다. 무효인 p를 유의하다고 전하지 않는다.
- **효과 크기를 함께 적는다.** 고요산혈증은 OR의 비, 요산은 β 차이(mg/dL)이다. 단위(10 g/일당, 두 배당, 최고 수준)를 밝힌다.
- **p < 0.05가 있으면** 몇 개의 검정 중 몇 개인지 함께 말하고, 기준을 여러 번 바꿔 본 결과라 우연일 수 있다고 적는다. 기준을 결과를 본 뒤 고르면 사후 선택이 된다.
- **모든 실행은 `output/21_ptest/ptest_log.csv`에 누적된다.** 보고서에는 시도한 기준 전체를 밝히도록 권한다.
- 주 모형은 Model 2, Model 3은 민감도 분석이라는 점을 필요할 때 짚는다.

## 4. 이 스킬이 하지 않는 것

- 결과 변수 정의(남 7.0, 여 6.0 mg/dL), 홍조 분류, 음주량 환산표를 바꾸는 일. 바꾸려면 `code/13`을 고쳐야 한다.
- OR 표, 그림, 보고서 작성. 그런 요청은 `code/22`·`code/23` 방식의 정밀 분석으로 한다.
- 이 연구가 아닌 다른 국건영 분석. 그때는 knhanes-analysis 스킬을 쓴다.
