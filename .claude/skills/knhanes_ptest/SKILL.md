# knhanes_ptest: 기준별 질문 p값 빠르게 구하기

기준을 받아 스크립트 하나를 실행하고, 질문별 p값 표를 한국어로 전한다. 한 번 실행에 10–20초 걸린다.
변수 정의·대상 선정·복합표본설계는 본 분석(`code/13_v3_main_analysis.R`의 0–3절)을 그대로 실행해 만들므로 본 분석과 같다.
프로젝트 규칙(CLAUDE.md)을 지킨다. `data/`는 읽기만 한다.

## 1. 사용자의 말을 옵션으로 바꾼다

| 사용자가 말한 것 | 옵션 |
|---|---|
| 남녀 같은 절단점 "5잔, 15잔" | `--cuts=5,15` |
| 남녀 다른 절단점 "남자 2.4·10, 여자 0.4·2.5" | `--male=2.4,10 --female=0.4,2.5` |
| 연속형 "하루 잔수로", "연속형으로" | `--drink=linear` (하루 1잔당 = 주 7잔당) |
| "log로", "두 배당" | `--drink=log2` (log2(잔/주 + 1)) |
| 보정변수 | `--covars="묶음1;묶음2"` (아래 표). 없으면 `Model 2;Model 3` |
| 혈청 요산(연속형 결과)도 | `--outcome=both` (요산만이면 `uacid`) |
| 폐경 후 여성 빼고 | `--pop=premeno` (남자는 전체 유지) |
| 임신·수유 여성 빼고 | `--pop=nopreg` |
| 기록에 남길 이름 | `--label="이름"` |

절단점은 **주당 잔수**다. `a,b`는 a 미만 / a 이상 b 미만 / b 이상의 3군이고, 경계 하나면 2군, 셋이면 4군이다. 남녀 절단점 개수는 같아야 한다.
사용자가 "하루 몇 g"으로 말하면 국건영 1잔 ≈ 7 g이므로 **g/일 = 잔/주**로 바꾼다고 알리고 그대로 쓴다.

### 보정변수 묶음

`;`로 묶음을 나누고, 묶음 안은 `+`로 잇는다. 프리셋, 변수 이름, `-변수`(빼기)를 섞을 수 있다.
예: `"Model 2;Model 2+he_bmi;age+f_edu+f_smk3;Model 3-egfr10"`

| 프리셋 | 변수 |
|---|---|
| Crude | 없음 |
| Model 1 | age |
| Model 2 (주 모형) | age, f_edu, f_incm, f_year, f_smk, f_pa |
| Model 3 | Model 2 + he_bmi, f_htn, f_dm, egfr10 |

| 변수 | 뜻 | 변수 | 뜻 |
|---|---|---|---|
| age | 연령(세) | age10 | 연령 10세 범주 |
| f_edu | 교육수준 | f_incm | 소득 4분위 |
| f_year | 조사연도 | f_pa | 유산소 신체활동 |
| f_smk | 현재흡연 2범주 | f_smk3 | 흡연 3범주(비·과거·현재) |
| he_bmi | 체질량지수 | egfr10 | eGFR(10 단위) |
| f_htn | 고혈압 유병(HE_HP) | f_htn_dx | 고혈압 의사진단 |
| f_dm | 당뇨병 유병(HE_DM_HbA1c) | f_dm_dx | 당뇨병 의사진단 |

목록에 없는 변수를 요청받으면 스크립트가 멈춘다. 그 변수를 쓰려면 지침서에서 정의를 확인해 `code/13`에 변수를 만든 뒤 `scripts/ptest.R`의 `cov_avail`에 추가해야 한다고 사용자에게 알린다.

## 2. 실행한다

프로젝트 폴더에서 R을 전체 경로로 실행한다. 기준이 여러 개면 순서대로 한 번씩 실행한다(같은 기록 파일에 쓰므로 동시에 돌리지 않는다).

```
& "C:\Program Files\R\R-4.6.0\bin\Rscript.exe" --vanilla .claude/skills/knhanes_ptest/scripts/ptest.R --male=2.4,10 --female=0.4,2.5 "--covars=Model 2;Model 3" "--label=성별 삼분위"
```

PowerShell에서는 공백이나 `;`가 든 옵션을 `"--covars=..."`처럼 통째로 따옴표로 감싼다.

## 3. 결과를 전한다

연구 질문(README 3절, 2026-11-16 개정):

- **주질문:** 남녀 각각에서, 성별 기준으로 나눈 음주 수준과 고요산혈증의 관계는 비홍조군과 지속 홍조군 사이에 연관성이 다른가?
- **부질문 1:** 남녀 각각에서, 같은 관계가 현재 홍조가 없는 사람 가운데 홍조 소실군과 비홍조군 사이에 다른가?
- **부질문 2:** 비홍조군과 지속 홍조군 사이의 연관성 차이가 남녀 사이에서도 다른가?

스크립트가 출력하는 검정은 다음과 같다(결과마다, 보정 묶음마다). 주질문과 부질문 1은 홍조 이력 3군(비홍조 기준·홍조 소실·지속 홍조)을 한 모형에 넣고 각 상호작용항을 검정한다.

| 구분 | 검정 | 대상 |
|---|---|---|
| 주질문 | 음주 × 지속 홍조 (비홍조 대비) | 남, 여 |
| 부질문 1 | 음주 × 홍조 소실 (비홍조 대비) | 남, 여 |
| 부질문 1(탐색) | 홍조 소실 vs 지속 홍조 | 남, 여 |
| 부질문 2 | 지속 홍조 vs 비홍조 차이 × 성별(보정변수 효과도 성별마다 다르게 둔 통합 모형) | 남녀 전체 |
| 부질문 2(탐색) | 지속 홍조 vs 비홍조 차이 × 폐경 | 여자(`--pop=premeno`면 생략) |
| 탐색적 분석 | 홍조 체질(과거 또는 현재 홍조) vs 홍조 없음 | 남, 여 |
| 참고 | 홍조 이력 세 군 공동, 현재 홍조 2군(계획 발표의 주질문)과 그 성별 3원 | 남, 여, 남녀 전체 |

전할 때 지킬 것:

- **질문별 p 표를 보여 준다.** 행은 질문, 열은 보정 묶음. 범주형이면 칸별 비가중 n(사례)도 요약한다.
- **비고를 빠뜨리지 않는다.** "사례 10명 미만 칸 있음"은 해석하지 않는 검정, "분리(추정 불가)"는 계산이 성립하지 않는 검정이다.
- **연속형이면 1 df 효과 크기를 함께 적는다.** 고요산혈증은 OR의 비(홍조군 기울기 ÷ 비홍조군 기울기), 요산은 β 차이(mg/dL)이다. 단위(하루 1잔당, 두 배당)를 밝힌다.
- **p < 0.05가 있으면** 몇 개의 검정 중 몇 개인지 함께 말하고, 기준을 여러 번 바꿔 본 결과라 우연일 수 있다고 적는다. 기준을 결과를 본 뒤 고르면 사후 선택이 된다.
- **모든 실행은 `output/21_ptest/ptest_log.csv`에 누적된다.** 보고서에는 시도한 기준 전체를 밝히도록 권한다.
- 주 모형은 Model 2, Model 3은 민감도 분석이라는 점을 필요할 때 짚는다.

## 4. 이 스킬이 하지 않는 것

- 결과 변수 정의(남 7.0, 여 6.0 mg/dL), 홍조 분류, 음주량 환산표를 바꾸는 일. 바꾸려면 `code/13`을 고쳐야 한다.
- OR 표, 그림, 보고서 작성. 그런 요청은 `code/22`·`code/23` 방식의 정밀 분석으로 한다.
- 이 연구가 아닌 다른 국건영 분석. 그때는 knhanes-analysis 스킬을 쓴다.
