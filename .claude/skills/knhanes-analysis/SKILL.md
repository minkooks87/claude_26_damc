# 국민건강영양조사 분석 절차

이 프로젝트에서 국건영 원시자료로 추정치를 내는 모든 작업은 아래 다섯 단계를 순서대로 따른다.
단계를 건너뛰면 결과는 나와도 틀릴 수 있고, 틀린 줄도 모르게 된다. 각 단계에 그 이유를 적어 두었다.

프로젝트 규칙(CLAUDE.md)도 함께 지킨다.
- `data/`는 읽기만 한다.
- 코드는 `code/`, 결과는 `output/`에 저장한다.
- 답변과 주석은 한국어로 쓴다.

## 도구

- R: `C:\Program Files\R\R-4.6.0\bin\Rscript.exe`
  - PATH에 없으므로 전체 경로로 실행한다.
  - PowerShell의 `r`은 R이 아니라 Invoke-History 별칭이다.
- 패키지: haven(sas7bdat 읽기), data.table, survey, pdftools(지침서 검색). 모두 설치되어 있다.
  - 새 패키지가 필요하면 설치 전에 사용자에게 묻는다.
- 이 스킬의 스크립트 (`.claude/skills/knhanes-analysis/scripts/`):
  - `search_guide.R`: 지침서 PDF에서 키워드를 찾아 PDF 쪽과 인쇄 쪽을 출력한다.
  - `analysis_template.R`: 1~5단계가 모두 들어 있는 분석 템플릿. `code/NN_주제.R`로 복사해서 쓴다.
  - `check_reproducibility.R`: 분석 스크립트를 새 세션에서 두 번 실행해 결과가 같은지 비교한다.

## 1단계. 이용지침서에서 변수 정의를 먼저 확인한다

변수의 뜻, 코드값, 조사 대상, 연도별 변경은 기억으로 정하지 않고 `docs/국건영 이용지침서/`에서 찾는다.
같은 변수 이름이라도 기수마다 코드나 조사 대상이 바뀌는 경우가 있다.
기억에 의존하면 그럴듯하지만 틀린 코드로 분석하게 된다.

```bash
Rscript .claude/skills/knhanes-analysis/scripts/search_guide.R "변수명|키워드" --doc=제7기
Rscript .claude/skills/knhanes-analysis/scripts/search_guide.R --doc=제7기 --page=93
```

- 분석 연도가 속한 **기수의 지침서**를 본다(2016–2018은 제7기, 2022–2024는 제9기).
  - 여러 기수를 합치면 기수마다 확인한다.
- PDF 표는 텍스트로 풀리면서 줄이 섞이므로, 검색으로 찾은 쪽은 `--page`로 통째로 읽고 확인한다.
- 확인한 내용은 템플릿의 `var_dict`에 적는다. 적을 내용은 변수, 코드=이름, 결측 코드, 비해당 처리, 출처(문서명, PDF 쪽 / 인쇄 쪽)이다.
  - 이 표는 `output/.../01_variable_definitions.csv`로 저장되어, 보고서의 변수 정의 근거가 된다.
- 결측 코드는 다음 기준으로 처리한다.
  - 9·99·999(모름·무응답)는 결측으로 처리한다.
  - 8·88·888(비해당)은 지침서에서 의미를 읽고 정한다. 예를 들어 "해당 경험 없음"이면 0, 조사 대상이 아니면 결측이다. 정한 근거 쪽수를 남긴다.
- 지침서에서 찾지 못하면 찾지 못했다고 사용자에게 말한다. 추측한 값을 사실처럼 쓰지 않는다.
- 자주 쓰는 확인 결과 (제9기 지침서):
  - `sex`, `age`, `psu`: PDF p.101 / 인쇄 p.93
  - `wt_itvex`, `kstrata`: PDF p.102 / 인쇄 p.94
  - age 80은 "80세이상" 탑코딩이다(같은 쪽 각주 1).
  - 복합표본 분석과 kstrata 설명: PDF p.43 / 인쇄 p.35
  - 통합가중치: 기수 내 PDF p.46 / 인쇄 p.38, 기수 간 PDF p.47 / 인쇄 p.39

## 2단계. 분석 대상은 행 삭제 없이 변수로 표시한다

연구 대상이 아닌 행을 지우지 않는다. 대신 `inc`(1 = 분석 대상, 0 = 제외) 변수를 만든다.

이유는 분산 추정 때문이다. 복합표본의 표준오차는 층과 집락 전체의 구조로 계산된다.
행을 먼저 지우면 어떤 층에서 집락이 사라질 수 있고, 그러면 표준오차가 틀어진다.
특히 19–39세처럼 일부 연령만 보거나, 결측 때문에 대상이 줄어들 때 문제가 커진다.

- 조건은 순서대로 적는다. 템플릿의 `criteria`가 각 조건 뒤에 남는 n을 `02_participant_flow.csv`(대상자 선정 흐름표)로 저장한다.
- 가중치(`wt_itvex`)가 결측인 사람은 검진·설문 미참여자이므로, 첫 조건으로 제외한다.
  - 2007–2021 기본DB에는 이런 사람이 연도마다 수백 명 있다. 2022–2024 기본DB에는 없다.
- 코드 처리 전후로 `nrow(d)`가 그대로인지 확인한다. 템플릿에 `stopifnot`이 들어 있다.

## 3단계. 가중치·층·집락을 지정하고 부분집단은 subset으로 분석한다

```r
d[is.na(wt_analysis), wt_analysis := 0]   # NA 가중치는 survey가 거부하므로 0으로 (inc = 0인 사람들)
des <- svydesign(ids = ~psu, strata = ~kstrata, weights = ~wt_analysis, nest = TRUE, data = d)
sub <- subset(des, inc == 1)
```

- 가중치는 분석 영역에 맞게 고른다.
  - 기본은 건강설문·검진 변수에 쓰는 `wt_itvex`이다.
  - 영양조사 변수가 들어가면 `wt_tot` 같은 다른 가중치가 필요할 수 있으므로 지침서 가중치 부분을 확인한다.
- 여러 연도를 합칠 때는 지침서의 통합가중치 계산식에 따라 연도별 통합비율을 곱한다(`pool_ratio`).
  - 근거 쪽수를 주석으로 남긴다.
  - 비율을 짐작으로 넣지 않는다. 비율 합이 맞지 않으면 모집단 크기 추정이 틀어진다.
- 2008년 일부 검사와 2009년 골관절염검사는 `kstrata` 대신 `kstrata1`/`kstrata2`를 쓴다(PDF p.43).
- 성별, 연령군 같은 하위 집단 분석도 `subset(sub, sex == "남자")`처럼 설계 객체에서 나눈다. 데이터를 나눈 뒤 설계를 다시 만들지 않는다.
- 회귀 등 본 분석도 모두 `sub`(또는 그 subset)에 대해 실행한다.
  - 예: `svyglm(..., design = sub)`, `svymean(~x, sub, na.rm = TRUE)`
- 층 안에 집락이 1개뿐인 경우(lonely PSU)는 템플릿이 경고한다.
  - 경고가 나오면 `options(survey.lonely.psu = ...)` 중 무엇을 쓸지 사용자와 정하고 보고서에 적는다.

## 4단계. Table 1은 비가중 n과 가중 추정치를 함께 적는다

- 범주형: 범주별 **비가중 n**과 **가중 % (SE)**
- 연속형: 응답자 **비가중 n**과 **가중 평균 (SE)**
- 비교 집단이 있으면 `by_var`로 열을 나눈다. 각 열도 `subset`으로 계산한다.

n은 실제로 조사된 사람 수라서, 추정이 얼마나 안정적인지 판단하는 근거가 된다.
가중 %는 모집단 추정치다. 둘 중 하나만 적으면 독자가 결과를 잘못 읽는다. 예를 들어 n = 12인 칸의 가중 30%를 믿을 만한 값으로 보게 된다.
가중 n(모집단 추정 인원)을 "n"이라고 적지 않는다.
표 아래 각주에는 다음을 적는다.
- 사용한 연도
- 가중치 변수
- "n은 비가중 표본 수, %와 평균은 복합표본 가중 추정치"라는 설명

결과는 `output/.../04_table1.csv`로 저장한다.

## 5단계. 마지막에 공식 통계 대조표와 재현성 확인을 한다

### 5-1. 공식 통계 대조표

내 코드로 공식 통계 1~2개를 재현해 본다. 예를 들어 같은 연도의 국민건강통계에 실린 만 19세 이상 비만 유병률 같은 값이다.
이 단계가 가중치, 층, 집락, 대상 정의, 변수 코딩을 한꺼번에 점검한다.
값이 맞으면 내 분석 파이프라인이 공식 방법과 같다는 근거가 된다.

- 공식값은 기억으로 채우지 않는다.
  - 국민건강통계 보고서나 KOSIS에서 찾아 출처(자료명, 연도, 표 번호, 쪽)를 함께 적는다.
  - 출처를 찾지 못하면 사용자에게 값을 받는다.
- 정의를 맞춘다. 연령 범위, 지표 정의, 조율(crude)과 연령표준화를 구분한다.
- 템플릿의 `official` 목록에 항목을 넣으면 `05_official_check.csv`가 만들어진다. 열은 추정치, SE, 95% CI, 공식값, 차이, CI 포함 여부이다.
- 공식값이 95% CI 밖이면 본 분석 결과를 보고하기 전에 원인을 찾는다.
  - 확인할 것: 가중치 선택, 대상 정의, 결측 코드, 탑코딩

### 5-2. 재현성 확인

```bash
Rscript --vanilla .claude/skills/knhanes-analysis/scripts/check_reproducibility.R code/NN_topic.R output/NN_topic
```

- 새 R 세션에서 분석 스크립트를 두 번 실행하고, 결과 CSV의 md5를 비교한다.
  - 판정은 `_reproducibility.txt`에 PASS/FAIL로 남는다.
- 템플릿은 입력 파일 지문(`_inputs.csv`: 크기·md5)과 `_sessionInfo.txt`를 남긴다.
  - 원시자료가 바뀌었거나 패키지 버전이 달라졌을 때 추적할 수 있다.
- 다음 상태에서는 재현이 안 된다. 분석 스크립트는 이런 상태 없이 처음부터 끝까지 돌아가야 한다.
  - 대화형 세션에만 있던 객체
  - 절대 경로
  - 시드 없는 난수
