# 요약 파일

각 주제 폴더의 `summaries/`에 논문마다 원문 파일과 같은 이름의 `.md` 파일이 있다. 원문을 저장한 논문은 원문 전체를, 저장하지 못한 논문은 초록을 근거로 썼으며, 각 파일의 '요약 근거' 줄에 표시하였다.

# 이 목록에 넣지 않은 것

문헌 조사 노트에 나오는 자료 가운데 논문이 아닌 것(NIAAA, CDC, WHO, 질병관리청, 보건복지부, 한국보건사회연구원 등의 지침·보고서·웹 문서와 기사)은 넣지 않았다. 노트가 해당 없음으로 판단한 보건사회연구 2019;39(1):293–333(https://doi.org/10.15709/hswr.2019.39.1.293)과, ResearchGate 주소로만 적혀 있어 서지를 확인하지 못한 식사의 질 연구 1건도 넣지 않았다.
