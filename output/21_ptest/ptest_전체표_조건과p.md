# /knhanes_ptest 전체 표: 조건(절단점·결과 변수·보정변수)과 질문별 p값

- 생성: `code/29_ptest_full_table.R`, 입력 `output/21_ptest/ptest_log.csv`. 한 줄 = 실행 하나 × 결과 변수 하나 × 보정 묶음 하나 (248줄).
- 자료: 국민건강영양조사 2019–2021, 최종 분석 대상 10,779명(남 5,411 · 여 5,368). 가중치 wt_itvex × 1/3, 층 kstrata, 집락 psu. p는 설계 기반 Wald F 검정.
- **절단점 단위는 g/일**(1잔 ≈ 7 g이라 g/일 = 주당 잔수). `a · b`는 a 미만 / a 이상 b 미만 / b 이상. 남녀 값이 다르면 성별 기준.
- **결과 변수:** 고요산혈증(남 7.0, 여 6.0 mg/dL 이상, 예/아니오) 또는 혈청 요산(mg/dL, **연속형**).
- **표시:** `*` p < 0.05 · `†` 비교하는 칸에 고요산혈증 사례 10명 미만이라 해석하지 않음 · `무효` 칸이 비어 계산이 성립하지 않음 · 빈칸 해당 검정 없음.
- 기준 16개 × 결과 2개 × 보정 묶음 6개를 함께 본 결과다. p < 0.05 하나를 확증으로 읽지 말고, 미리 정한 주분석 기준과 주 모형(M2)을 먼저 해석한다.

## 1. 각 p값이 무엇인가

| 열 | 무엇에 대한 p인가 |
|---|---|
| 주 남 / 주 여 | **주질문.** 남자(여자)에서 음주량과 결과의 관계가 **지속 홍조군과 비홍조군 사이에 다른가** (음주 × 지속 홍조 상호작용) |
| 부1 남 / 부1 여 | **부질문 1.** 남자(여자)에서 같은 관계가 **홍조 소실군과 비홍조군 사이에 다른가** (음주 × 홍조 소실 상호작용) |
| 부2 성별 | **부질문 2.** 지속 홍조군과 비홍조군의 차이가 **남녀 사이에 다른가** (음주 × 홍조 × 성별 3원 상호작용) |
| 부2 폐경 | **부질문 2(탐색).** 같은 차이가 **여성의 폐경 전과 후에 다른가** (음주 × 홍조 × 폐경 3원 상호작용) |
| 주 경향 · 부1 경향 | 주질문·부질문 1과 같은 질문을, 범주별 g/일 중앙값을 점수로 넣은 **1 df 경향성 검정**으로 본 p (범주형이고 경향성검정 = 예일 때만) |
| 부2 경향 성별 | 부질문 2와 같은 질문의 1 df 경향성 검정 p |
| 소실vs지속 | 홍조 소실군과 지속 홍조군 사이의 차이 (탐색) |
| 탐색(홍조 체질) | 과거 또는 현재 홍조가 있는 사람 vs 한 번도 없는 사람 (계획서에 없던 탐색 분석) |
| 비선형성 | 스플라인일 때, 음주량과 결과의 관계가 **직선에서 벗어나는가** |
| 참고 현재홍조 | 계획 발표 때의 주질문: 현재 홍조군 vs 현재 비홍조군 |
