## 6. 권고안 (팀 확정 필요)

1. **모형 구성**: 1절의 표대로 Crude, Model 1, Model 2, Model 3을 쓴다. 결과를 본 뒤 구성을 바꾸지 않는다.
2. **주 모형은 Model 2, Model 3은 민감도 분석.** Model 2에 임상 변수를 하나씩 넣었을 때 고음주 OR을 가장 크게 움직인 변수는 남자에서 eGFR이었다(남자 +12.9%, 여자 +4.2%). eGFR은 요산과 서로 영향을 주고받고 음주가 크레아티닌에 영향을 줄 수 있어 교란변수로 단정하기 어렵다. 체질량지수·고혈압·당뇨병도 음주가 요산에 이르는 중간 경로일 수 있다. 그래서 교란변수만 넣은 Model 2를 주 결과로, 임상 지표까지 넣은 Model 3을 보정을 더 해도 결론이 같은지 보는 용도로 쓴다.
3. **상호작용은 상호작용항 공동 검정을 주 검정으로, RERI를 보조로 쓴다.** 두 척도의 결론이 같다. 상호작용 p는 네 모형, 변수를 하나씩 넣은 모든 단계, 네 가지 규칙에서 0.39–0.74였다.
4. **흡연은 3범주(비흡연·과거·현재)로 바꾸기를 권한다.** 과거흡연을 비흡연과 나누면 Model 2의 고음주 주효과 OR이 남자 1.45 (1.19–1.77)에서 1.39 (1.13–1.71)로, 여자 2.11 (1.43–3.10)에서 2.03 (1.37–3.00)로 달라진다. 진행 기록 문서의 흡연 3범주 인원과 이 자료의 인원은 모두 일치한다.
5. **임신·수유 여성 제외는 채택해도 결과가 거의 같다.** 해당자는 4명이고, 여자 Model 2의 고음주 주효과 OR은 2.11 (1.43–3.10)에서 2.12 (1.44–3.12)가 된다. 채택하면 최종 인원은 10,775명이다.
6. **보정변수 목록**: 기본 6개(연령, 교육수준, 소득, 조사연도, 흡연, 유산소 신체활동)와 임상 4개(체질량지수, 고혈압, 당뇨병, eGFR).

권고 4·5를 채택하면 주 분석을 그 규칙으로 다시 돌리고, 보고서의 모형 이름도 Crude·Model 1–3으로 바꿔야 한다. 이 문서의 2–4절 수치는 현재 규칙(R0) 기준이다.
