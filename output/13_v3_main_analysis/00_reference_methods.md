## 2. 본 분석에 반영한 것 (연구계획서·발표 v5·V3 정의가 기본, 논문은 세부 방법의 근거)

| 항목 | 결정 | 근거 |
|---|---|---|
| 자료·가중치 | 2019–2021 기본DB, wt_itvex × 1/3, 층 kstrata, 집락 psu, 분석 대상은 행 삭제 없이 도메인(subset)으로 지정 | 8기 지침서 PDF p.36(통합비율), Kang B 2024(2개년 ×0.5, 도메인 분석) |
| 대상 | 만 19세 이상 최근 1년 음주자, 음주량·과거/현재 홍조·요산 확보, 통풍 의사진단(모름 포함) 제외, 보정변수 완전 응답 | 연구계획서·V3 |
| 음주량 | 1회량 중앙값(1.5·3.5·5.5·8, 10잔 이상은 BD2_14 기입값) × 주당 빈도(월0.5·1·3회, 주2.5·5.5회) → 저 <3.5 · 중 3.5–14 · 고 ≥14잔/주 | V3; 1회량 중앙값 방식은 Lee 2023과 동일 |
| 추세 검정 | 음주 수준을 순서형(0·1·2)으로 넣어 홍조군별 P for trend 제시 | Lee 2022(층별 삼분위 P for trend) |
| 홍조 | 주분석: 현재 홍조(가끔 이상) 2군. 부가: 이력 3군(비홍조·소실·지속, 신규 제외). 보조: 4군 | V3; 4군 분류는 Yook 2024와 동일; Lee 2023의 홍조군은 본 분석의 '지속 홍조' vs '비홍조'에 해당 |
| 결과 | 고요산혈증 남 ≥7.0 · 여 ≥6.0 mg/dL; 여성은 혈청 요산 연속형 추가(남성은 보조) | V3, Bae 2023; 연속형+이분형 병행은 So 2020 |
| 모형 | 남녀 따로 복합표본 로지스틱, M0 연령보정 → M1 기본(연령·교육·소득·연도·흡연·신체활동) → M2 확장(+BMI·고혈압·당뇨병 유병·eGFR) | V3; 단계적 보정은 Kang & Oh 2023, Yook 2024 |
| 상호작용 | '음주 수준 × 현재 홍조' 곱셈항 공동 Wald 검정 + 홍조군별 층화 OR(단순효과) + 덧셈 척도 RERI(델타법 95% CI) + 결합효과 OR(기준: 비홍조·저음주) | V3, Kang & Oh 2023, Kang B 2024, Moore 2016 |
| 성별·폐경 | 3원 상호작용(음주×홍조×성별), 여성 폐경 전·후 층화(탐색) | V3; 성별 상호작용 사전 지정은 So 2020 |
| 기술통계 | 비가중 n + 가중 %(SE)/평균(SE), Rao-Scott χ²·설계 기반 Wald | V3, Kang B 2024 |
| 민감도 | 통풍 진단자·무응답자 포함, 대표값 변경, 2020년 제외, 폭음 빈도 노출, '자주·늘'만 홍조('가끔' 제외: Kang & Oh 방식), 성별 삼분위, 의사진단 보정, 월1회 초과 빈도 2군(Kang & Oh 방식) | 계획서·V3·논문 |

- 논문과 다르게 한 것: Kang & Oh 2023은 가중치 적용 언급이 없고 '가끔'을 제외했지만, 본 분석은 가중치를 적용하고 주분석에서는 '가끔'을 홍조에 포함한다(V3). So 2020의 단일 기준(≥6.0)은 쓰지 않는다(V3 성별 기준). Moore 2016의 RERI 신뢰구간은 MOVER법이지만 본 분석은 델타법을 쓴다.
